# PPS-Lab-Experiments

This repository contains C programming solutions for weekly lab experiments. The code is organized into subfolders corresponding to each week.

## Repository Structure

* [Week-1](./Week-1) - Basic Input and Output

* [Week-2](./Week-2) - Basic Arithmetic and Interest Calculations

* [Week-3](./Week-3) - Mathematical Formulas and Geometry

* [Week-4](./Week-4) - Expression Evaluation and Conditional Logic

* [Week-5](./Week-5) - Decision Making(if-else)

  ---

  ## Index of Experiments

### [Week-1](./Week-1)  

* **Experiment 1: **[AGEPRINTING.c](./Week-1/AGEPRINTING.c) - Simple C program using 'printf()' and 'scanf()'.

### [Week-2](./Week-2)

* **Experiment 1: **[CEL&FAH.c](./Week-2/CEL&FAH.c) - Program to convert temperature from Fahrenheit to Celsius and vice versa.
  
* **Experiment 2: **[SIMPLEINTEREST.c](./Week-2/SIMPLEINTEREST.c) -Program to calculate Simple Interest given principal_amount, rate,                         and  time
  
*  **EXPERIMENT 3: **[SUMAVG.c](./Week-2/SUMAVG.c) - Program to calculate the sum and average of 3 numbers.

### [Week-3](./Week-3)

* **Experiment 1: **[AREA_HERONS.c](./Week-3/AREA_HERONS.c) - Program to calculate area of a triangle using Heron's formula.

*  **Experiment 2: **[COMPOUND_INTEREST.c](./Week-3/COMPOUND_INTEREST.c) - Program to find compound interest given the principal amount,                     rate of interest and time period.

*  **Experiment 3: **[DISTANCE_TRAVELLED.c](./Week-3/DISTANCE_TRAVELLED.c) - Program to compute the distance travelled by an object.

*   **Experiment 4: **[SQUAREROOT.C](./Week-3/SQUAREROOT.c) - Program to find  the square root of a given number.

### [Week-4](./Week-4)

* **Experiment 1: **[GIVEN_SUMS.c](./Week-4/GIVEN_SUMS.c) - Program to evaluate specific operators and precedence expressions.

*  **Experiment 2: **[MARKSHEET.c](./Week-4/MARKSHEET.c) - Program to accept marks for 5 subjects and to calculate the total and floating point                      average

*  **Experiment 3: **[MAX_3.c](./Week-4/MAX_3.c) - Program to find the maximum of three numbers using the conditional(ternary) operator.

### [Week-5](./Week-5)

* **Experiment 1: **[LEAPYEAR_ORNOT.c](./Week-5/LEAPYEAR_ORNOT.c) - Program to find a given year is leap year or not.

* **Experiment 2: **[MAX_MIN.c](./Week-5/MAX_MIN.c) - Program to find the maximum and minimum of four given numbers using if-else blocks. 

*  * **Experiment 3: **[ROOTS_OFEQN.c](./Week-5/ROOTS_OFEQN.c) - Program to find the roots of a quadratic equation.

* **Experiment 4: **[CALCULATOR.c](./Week-5/CALCULATOR.c) - Menu-driven program to perform basic arithmetic operations.
  
* **Experiment 5: **[ELECTRICITY_BILL.c](./Week-5/ELECTRICITY_BILL.c) - Program to calculate household electricity bill based on consumption slabs.
